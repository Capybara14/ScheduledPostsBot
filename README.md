Бот для автоматического управления отложкой в telegram.

База данных реализована на основе Upstash-redis и хранит все необходимые для работы данные и настройки в нём же, ничего локально не сохраняется.

Бот сохраняет в очередь все картинки и видео, которые вы в него закинете и постит по расписанию.
При этом бот сохраняет все посты в хеш и не позволяет запостить одинаковые файлы.

В интерфейсе бота в telegram можно настроить канал, где будут выходить посты, добавить админов бота, которые имеют полный доступ к его управлению, выложить пост не по расписанию ("Отправить сейчас") а так же имеются базовые функции управления очередью: просмотр по элементам, удаление выбранных элементов и очистка всей очереди.
